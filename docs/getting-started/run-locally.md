# Run Locally

By [Kiwan Maeng](https://kiwanmaeng.com) ([LinkedIn](https://www.linkedin.com/in/kiwan-maeng-23b825165)) and [Claude Code](https://claude.com/claude-code) 🤖

Any Linux, macOS, or Windows (WSL2) machine with **Python 3.10–3.12**, **git**, and
**4 GB of RAM** is enough.

## 1. Get the course

```bash
git clone https://github.com/kwmaeng91/studying-llm-systems-without-gpus
cd studying-llm-systems-without-gpus
```

## 2. Create an environment

```bash
python3 -m venv .venv
source .venv/bin/activate          # Windows (WSL): same command
pip install -r requirements-lab.txt jupyterlab
```

## 3. Launch Jupyter

```bash
jupyter lab docs/lectures/
```

Open any `.ipynb` and run the first cell. `lsg.setup()` downloads the simulator into
`~/.llm-systems-wo-gpus/backend` the first time.

## Where things are stored

| Path | Contents | Safe to delete? |
|---|---|---|
| `~/.llm-systems-wo-gpus/backend/` | simulator source and profiling data (~700 MB) | yes, re-downloaded on next `setup()` |
| `~/.llm-systems-wo-gpus/predictor_cache/` | fitted runtime predictors (~70 MB per model/GPU/TP) | yes, refit on demand |
| `~/.llm-systems-wo-gpus/runs/` | raw simulator output of every run | yes |
| `~/.llm-systems-wo-gpus/traces/` | workload CSVs generated by `make_trace` | yes |

Set the `LSG_WORK_DIR` environment variable to use a different directory than
`~/.llm-systems-wo-gpus`, or `LSG_BACKEND_DIR` to move only the simulator.

## Troubleshooting

`RuntimeError: Simulation failed`
: The simulator's log is printed above the error. The most common cause is an
  unprofiled combination (for example Llama-3-8B with TP2 on A100). Check `lsg.catalog()`.

The first simulation of a new model or GPU is slow
: The simulator fits its runtime predictors once per (model, GPU, TP) and caches them.
  Later runs take a few seconds.

Out of memory
: The labs keep the simulator's prediction grid small (see `LITE_GRID` in
  `llm_systems_wo_gpus.py`). If you raise those limits, expect memory use to grow
  quickly. The upstream defaults need more than 10 GB.
